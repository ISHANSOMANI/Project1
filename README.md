# StudyClock TIET
Native Android study timer for TIET Pool B Semester 1.

Preloaded courses:
- UPH013 Physics
- UES101 Engineering Drawing
- UHU003 Professional Communication
- UES102 Manufacturing Processes
- UMA023 Differential Equations & Linear Algebra

Core workflow: choose course -> optional topic -> start -> pause/resume -> stop & save -> session records/stats.
The foreground service keeps the timer running while the app is in the background.

## Build
GitHub Actions builds `app-debug.apk` on every push to `main`.
